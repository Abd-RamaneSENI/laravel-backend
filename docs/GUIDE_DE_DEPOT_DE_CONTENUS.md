# Guide des contenus a deposer

Ce document indique quoi preparer avant d'ajouter un contenu dans SENI-CNF EDU. Ne publier que des contenus originaux, libres de droits ou pour lesquels vous possedez une autorisation ecrite de diffusion et de vente.

## 1. Ressource numerique payante

Utiliser cette categorie pour les cours, exercices, corriges, annales ou fiches proposes a la vente.

A preparer avant le depot :

- Le fichier final : PDF, DOC, DOCX, PPT, PPTX, XLS ou XLSX, 30 Mo maximum.
- Un titre clair et unique.
- Une description utile : niveau, contenu, objectifs et nombre de pages lorsque connu.
- Le cycle, la classe, la matiere et le type de ressource.
- L'annee scolaire si elle est utile.
- Le prix en francs CFA.
- Une declaration de droits : auteur, titulaire des droits, ou preuve d'autorisation de diffusion.

Depot : ouvrir `Administration` puis `Ajouter et publier`. Le fichier est range dans le stockage prive et devient telechargeable seulement apres paiement confirme.

## 2. Livre physique a emprunter

Utiliser cette categorie pour les ouvrages disponibles dans la bibliotheque physique.

A preparer :

- Titre du livre.
- Auteur. Si absent de la liste, utiliser le petit bouton `+` situe a cote du champ Auteur pour le creer.
- Categorie du livre.
- ISBN si disponible.
- Annee de publication et emplacement sur l'etagere.
- Nombre d'exemplaires reellement disponibles dans la bibliotheque.
- Description courte du contenu.

Depot : dans le catalogue unifie, aller a la section `Bibliotheque physique`, ouvrir `Ajouter un livre`, puis choisir `Livre physique` dans le menu.

## 3. Document PDF associe a un livre

Utiliser cette categorie pour un document que les utilisateurs peuvent lire dans leur navigateur, sans bouton de telechargement.

A preparer :

- Un fichier PDF lisible, 30 Mo maximum.
- Le titre du document.
- Une description courte indiquant ce que le lecteur y trouvera.
- Une confirmation que sa diffusion en lecture est autorisee.

Depot : dans la section `Bibliotheque physique` du catalogue, utiliser `Ajouter un PDF` sur le livre concerne. Le lecteur doit avoir emprunte ce livre avant de pouvoir ouvrir le document.

Le document est sauvegarde dans le stockage prive. Les lecteurs connectes le consultent dans le navigateur. L'administrateur voit les lecteurs actifs dans le tableau de bord ; une presence expire apres deux minutes sans activite.

## Controle avant publication

1. Ouvrir le contenu et verifier les pages, le titre et les informations affichees.
2. Verifier que les droits de diffusion sont documentes.
3. Pour une ressource payante, verifier le prix et les informations scolaires.
4. Pour un livre, verifier le nombre d'exemplaires et l'emplacement.
5. Pour un PDF de consultation, tester la lecture avec un compte lecteur.
